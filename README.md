# Loja de Cupcakes

Projeto acadêmico em desenvolvimento para a disciplina "Projeto Integrador Transdisciplinar em Engenharia de Software II".

## Objetivo

Desenvolver uma loja virtual de cupcakes com catálogo, carrinho e registro de pedidos.

## Funcionalidades implementadas

- Exibição de um cupcake com descrição e preço.
- Adição e remoção de unidadades no carrinho.
- Opção de esvaziar o carrinho.
- Cálculo do total em reais.
- Desativação dos botões de remover e esvaziar quando o carrinho está vazio.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar esta versão

1. Baixe os arquivos do projeto.
2. Mantenha index.html, style.css e script.js na mesma pasta.
3. Abra o index.html em um navegador.

## Limitações atuais

O carrinho contém apenas um produto e é reiniciado ao atualizar a página. Cadastro, pedidos, pagamento simulado e servidor em Python ainda não foram implementados.
